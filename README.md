sec-host-header
================

密码重置邮件里的链接被改成了攻击者的域名，因为服务端直接信了请求里的主机头：主机头必须在白名单内且精确匹配；带端口与不带端口按同一规则归一；绝对请求行里的主机必须与主机头一致；重复主机头必须拒绝；主机头不得含用户信息或路径；缺失主机头按协议要求拒绝；批量校验各请求独立。不变量：同一请求两次校验结果相同；构造出来的链接主机必定在白名单内。

## 安全背景

密码重置邮件会携带一次性令牌，链接主机一旦可由请求方控制，令牌就会发往攻击者域名。本仓库把主机头视为不可信输入，围绕解析、归一、白名单、绝对请求行、重复头、缺失头、链接生成和批量校验建立防线。

## 接口

请求使用映射表示，包含 headers、target、allowlist 三个字段；headers 可写成名称与值的二元组列表，以保留重复头；scheme 字段和 build_url 的参数均可指定协议。

- parse_host 返回 host 与 port，遇到非法输入抛出 ValueError。
- normalize_host 返回小写主机，并按协议去掉默认端口。
- allowlisted 判断主机是否在白名单内，比较前统一大小写并做精确匹配。
- check_absolute_uri 判断绝对请求行中的主机与主机头是否一致。
- check_duplicates 在出现多个主机头时返回 True。
- build_url 使用通过校验的主机和端口生成外部链接。
- validate_request 返回问题代码列表，覆盖缺失主机、重复主机头、非法端口、用户信息、路径、白名单和绝对请求行不一致。
- host_batch 按请求下标返回各自的校验结果。
